An autonomous AI Voice Assistant inspired by Marvel's Iron Man J.A.R.V.I.S., engineered to run **both locally on any laptop with 1-click** and **live on the cloud 100% free forever** on Streamlit Community Cloud.

---

## 💻 1-Click Run on Any Laptop (Windows & Mac)

Anyone who downloads or clones this repository can launch Jarvis immediately:

### On Windows:
1. Download or clone this repository.
2. Double-click **`run_jarvis.bat`**.
3. It automatically creates the environment, installs all dependencies, and opens the animated JARVIS HUD in your browser!

### On macOS / Linux:
1. Download or clone this repository.
2. Open terminal in the folder and run:
   ```bash
   ./run_jarvis.sh
   ```

---

## 🚀 1-Click Free Cloud Deployment (Streamlit Cloud)

To run it live on the web forever at zero cost:
1. Visit [Streamlit Community Cloud](https://share.streamlit.io/).
2. Select repository `yashraj2408/Jarvis`, branch `main`, and main file `streamlit_app.py`.
3. Click **Deploy!**

## 🌟 Key Features
- **⚡ Stark Industries HUD**: Futuristic animated glowing Arc Reactor interface with telemetry stats.
- **🎙️ Native Browser Microphone**: Click the microphone button to grant access and speak directives hands-free.
- **🔊 British Voice Synthesis**: Speaks responses back aloud using natural British AI speech (`gTTS`).
- **🌦️ Satellite Meteorological Radar**: Live real-time global weather scans for any city.
- **🎵 YouTube Audio Streamer**: Locates and embeds music/videos directly inside the interface.
- **📚 Wikipedia Knowledge Engine**: Instant encyclopedia dossier search on any topic, person, or historical event.
- **🛡️ Protocol House Party & Easter Eggs**: Fun Stark Industries lore and system diagnostics.
