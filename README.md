An autonomous, interactive AI Voice Assistant inspired by Marvel's Iron Man J.A.R.V.I.S., engineered for **lifetime free cloud deployment** on Streamlit Community Cloud.

---

## 🌟 Key Features
- **⚡ Stark Industries HUD**: Futuristic animated glowing Arc Reactor interface with telemetry stats.
- **🎙️ Web Speech Voice Recognition**: Uses the browser's native Web Speech API to recognize voice commands hands-free.
- **🔊 British Voice Synthesis**: Speaks responses back aloud using natural British AI speech (`gTTS`).
- **🌦️ Satellite Meteorological Radar**: Live real-time global weather scans for any city.
- **🎵 YouTube Audio Streamer**: Locates and embeds music/videos directly inside the interface.
- **📚 Wikipedia Knowledge Engine**: Instant encyclopedia dossier search on any topic, person, or historical event.
- **🛡️ Protocol House Party & Easter Eggs**: Fun Stark Industries lore and system diagnostics.
